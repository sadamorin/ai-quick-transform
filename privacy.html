AI Quick Transform

プライバシーポリシー

貞森 龍生（以下「当方」といいます）は、Chrome 拡張機能「AI Quick Transform」（以下「本拡張機能」といいます）における利用者の情報の取り扱いについて、以下のとおり定めます。

1. 取り扱う情報

情報利用目的 / 保存・送信先
選択したテキスト、または閲覧中のWebページの本文・タイトル・URLAI による要約・変換処理のため、利用者が選択した AI 提供元（Google または OpenAI）へ、AI 処理を実行したときに限り送信します。
利用者が入力した API キー利用者のブラウザ内（chrome.storage.sync）に保存し、対応する AI 提供元への通信にのみ使用します。
設定内容、1日の利用回数、直近の変換結果機能の提供のため、利用者のブラウザ内にのみ保存します。
有料プランのお申し込み時のメールアドレス、決済情報有料プランの決済・契約管理のため、決済サービス ExtensionPay および Stripe が取り扱います。

2. 当方のサーバーへの送信について

本拡張機能は、上記の情報を当方が運営するサーバーへ送信・保存しません。AI 処理のためのテキストは、利用者のブラウザから各 AI 提供元へ直接送信されます。

3. 決済情報について

有料プランの決済は、ExtensionPay（extensionpay.com）を通じて Stripe が処理します。

  • 当方は、クレジットカード番号などの決済情報を取得・保存しません。
  • 当方は、契約管理およびお問い合わせ対応のために、ExtensionPay を通じてお申し込み時のメールアドレスと契約状況を確認できます。

4. 第三者への提供

当方は、法令に基づく場合を除き、利用者の情報を第三者に販売・提供しません。また、本拡張機能は広告の配信やアクセス解析を目的とした情報の収集を行いません。

各外部サービスでの情報の取り扱いについては、それぞれのプライバシーポリシーをご確認ください。

  • Google（Gemini API）：プライバシーポリシー ／ Gemini API 利用規約
  • OpenAI：プライバシーポリシー
  • Stripe：プライバシーポリシー
  • ExtensionPay：extensionpay.com
Google Gemini API の無料枠をご利用の場合、送信した内容が Google のサービス改善に利用されることがあります。機密情報の送信にはご注意ください。

5. Chrome ウェブストアのユーザーデータポリシーへの準拠

本拡張機能によるユーザーデータの使用は、Chrome ウェブストアのユーザーデータに関するポリシー（「限定使用」の要件を含む）に準拠します。

6. 情報の削除

ブラウザ内に保存された情報（API キー、設定、利用回数、変換結果）は、本拡張機能をアンインストールすることで削除されます。

7. 本ポリシーの変更

当方は、必要に応じて本ポリシーを変更することがあります。変更後のポリシーは、本ページに掲載した時点から効力を生じます。
